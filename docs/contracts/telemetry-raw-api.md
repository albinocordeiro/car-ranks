# `GET /v1/telemetry/raw`

Purpose: Inspect raw OBD command/response snippets that were persisted during telemetry ingest.

Auth: requires `x-user-id: <uuid>` and vehicle ownership/access.

## Query

Required:
- `vehicle_uid` (UUID)

Optional:
- `limit` (integer, default `120`, min `1`, max `500`)
- `signal_key` (string, exact match)
- `include_session_events` (`true|false`, default `false`)
- `batch_id` (UUID)
- `session_id` (UUID)
- `cursor_observed_at` (RFC3339 timestamp)
- `cursor_observation_id` (UUID/text id)

Cursor rules:
- `cursor_observed_at` and `cursor_observation_id` must be provided together.
- Empty cursor values are rejected.
- `cursor_observed_at` must parse as RFC3339.

Filter behavior:
- `batch_id` filters signal rows by ingest batch.
- `session_id` filters both signal rows and session-event rows.
- Session-event rows are only included when `include_session_events=true` and no `batch_id` filter is provided.

## Example Requests

Latest raw rows for a vehicle:

```bash
curl -H 'x-user-id: <user_uuid>' \
  "http://127.0.0.1:8080/v1/telemetry/raw?vehicle_uid=<vehicle_uuid>&limit=50"
```

Filter by capture session and include session events:

```bash
curl -H 'x-user-id: <user_uuid>' \
  "http://127.0.0.1:8080/v1/telemetry/raw?vehicle_uid=<vehicle_uuid>&session_id=<session_uuid>&include_session_events=true&limit=200"
```

Next cursor page:

```bash
curl -H 'x-user-id: <user_uuid>' \
  "http://127.0.0.1:8080/v1/telemetry/raw?vehicle_uid=<vehicle_uuid>&limit=200&cursor_observed_at=2026-02-22T06%3A12%3A19.984Z&cursor_observation_id=3c34b71a-13b4-4e7f-9894-75d8b566f0f7"
```

## Notes

- Rows are sorted by `(observed_at desc, observation_id desc)`.
- Only rows with non-null `raw_payload_ref` are returned.
- Session-event rows use `signal_key` format `session.<session_type>.<event_type>`.
- `raw_payload_ref` is a compact command/response or command/error snippet generated by capture code.
- Pagination is seek-based via cursor fields (no offset pagination).
