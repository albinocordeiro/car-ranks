# Car Ranks Support

Last updated: 2026-02-20

If you need help with Car Ranks, use one of the channels below:

- Support issues: https://github.com/albinocordeiro/car-ranks/issues
- Project repository: https://github.com/albinocordeiro/car-ranks

When opening a support issue, include:

- App version
- iOS version
- Device model
- Steps to reproduce
- Screenshot or error text (if available)
