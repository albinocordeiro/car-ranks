# App Store Submission Package (MVP)

Status: Draft v1  
Date: 2026-02-20  
Goal: centralize all App Store and TestFlight submission artifacts for the MVP ship window.

## Files

- `app-store-metadata.md`: app name/subtitle/description/keywords/category draft for App Store Connect.
- `app-privacy-questionnaire.md`: draft data-collection mapping for App Privacy responses.
- `app-review-notes.md`: draft notes for Apple App Review, including key test flow and constraints.
- `screenshot-plan.md`: screenshot matrix and capture checklist for required device classes.
- `testflight-qa-checklist.md`: release-candidate QA gate before TestFlight/App Store submission.

## How To Use

1. Finalize values in each file marked `TODO`.
2. Copy finalized content into App Store Connect fields.
3. Keep this folder as the source of truth for release updates.
4. Update `/Users/albinocordeiro/Code/car_ranks/docs/mvp-release-checklist.md` statuses after each artifact is finalized.
